Recovery actions

Do not use these actions during normal operation. Use them only when the panel reports an unreadable state, a failed state load, or an unknown command outcome.

What each action does

Start reveal
Starts a new ceremony, or resumes an idle ceremony using its existing frozen snapshot.
Start over
Discards the current ceremony, rebuilds it from current contest data, and starts revealing.
Rebuild state
Replaces unreadable stored state with a new snapshot from current contest data, then starts revealing.
Reset to idle
Clears reveal progress while preserving the original frozen snapshot. It does not start the ceremony.
Reload state
Reads the authoritative stored state without changing it. Use it when a command may have completed but its response was lost.
Show media / Hide media
Puts the focused team's photo and audio clip on every projector watching this ceremony, or takes it down again. It changes no ceremony state, so it is always safe to press twice, and the next Step, Back, or Jump takes the overlay down on its own. A projector that was disconnected at that moment never receives the cue — press again.
