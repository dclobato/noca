Always update `docs/ROUTES.md`, `docs/URL_FOR_REFERENCE.md`, and `docs/SERVICES.md` as part of every change that adds, removes, or modifies routes or service entrypoints. Do not wait to be asked.

**Why:** User had to explicitly ask after a session where several routes and service functions were added without the docs being updated.

**How to apply:** After implementing any route or service change, immediately update the relevant doc sections before considering the task complete.
