# Noca Arena — Favicon Pack

Drop these files into the **root** of your site (or update the paths in `snippet.html`).

## Files

| File | Size | Use |
|------|------|-----|
| `favicon.ico` | 16+32+48 multi-size | Legacy browsers, default tab icon |
| `favicon-16x16.png` | 16×16 | Browser tab (small) |
| `favicon-32x32.png` | 32×32 | Browser tab (retina) |
| `favicon-48x48.png` | 48×48 | Windows site icon |
| `favicon-96x96.png` | 96×96 | Android home shortcut |
| `favicon-180x180.png` | 180×180 | Apple touch icon (iOS) |
| `android-chrome-192x192.png` | 192×192 | Android Chrome / PWA |
| `android-chrome-512x512.png` | 512×512 | Android Chrome splash / PWA |
| `mstile-150x150.png` | 150×150 | Windows tile |
| `site.webmanifest` | — | PWA manifest (Android) |
| `browserconfig.xml` | — | Windows tile config |

## Colors

- Green: `#2f9e41` (Accepted)
- Red: `#cd191e` (Wrong Answer)
- Cream background: `#fff8e7`
