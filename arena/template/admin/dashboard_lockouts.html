{{ render_icon(icon="lock_open") }} Sign-in lockouts

After repeated failures the sign-in, two-factor, password-reset and password-confirmation steps refuse an account or an address for a while. Lift that early here. Every unlock is password-confirmed and recorded in the security audit log; it clears Arena buckets only. Unlocking something that is not locked changes nothing, so it is safe to try.
