{{ render_icon(icon="lock_open") }} Sign-in lockouts

After repeated failures the sign-in, two-factor, password-reset and password-confirmation steps refuse an account or an address for a while. Lift that early here. Every unlock is password-confirmed and recorded in the security audit log; it clears Arena buckets only. Unlocking something that is not locked changes nothing, so it is safe to try.

Unlock an address

Clears the failure counters and locks of one IPv4 or IPv6 address across every Arena sign-in step. Everyone behind that address is unblocked.

Unlock a user

Enter the email address the user signs in with. A known account is unlocked in every step at once; an unknown address is unlocked exactly as it was typed. The address itself stays locked: use the form beside this one for that.
