LaTeX and Mermaid Syntax

LaTeX

Use inline math with single $: 

$x^2 + y^2 = z^2$

Common symbols:

\frac{a}{b} → fraction
x_2 → subscript
\neq, \le, \ge → ≠, ≤, ≥
\alpha, \beta, \Omega → Greek letters
\sum, \int → Σ, ∫
\sqrt{x} → square root

Mermaid

Use fenced code block with mermaid: 

```mermaid
graph TD
    A[Start] --> B{Decision}
    B -->|Yes| C[End]
    B -->|No| D[Loop]
    D --> B
```

Keywords:

flowchart, sequenceDiagram, classDiagram
-->, ---, ==> → arrows
[], {}, () → shapes
|text| → labels
