You become the owner of the imported problem. Its packaged author is preserved, it is created disabled, and all test cases are imported as secret.

{{ render_icon(icon="folder_zip") }} Expected package contents 

/
├── problem.json
├── statement.md
├── image.png            (optional)
├── in/
│   ├── 001.in
│   └── 002.in
├── out/
│   ├── 001.out          (or 001.sol)
│   └── 002.out          (or 002.sol)
└── explanation/         (optional)
    └── 001.txt

A flat test-case layout (001.in / 001.out or 001.sol at the root) is also accepted.

problem.json fields

Field Type Required
title string required
author string (maximum 80 characters) optional
time_limit_ms integer required
memory_limit_kb integer required
pids_limit integer required
output_limit_in_bytes integer or null optional
source string or null optional
hide_author_show_source boolean optional
categories array of strings optional
image filename string or null optional
image_caption string or null optional
notes string or null optional
license string (maximum 256 characters) or null optional

Validation rules

  • statement.md is required and must not contain external links, images, or URLs.
  • At least one input/output test-case pair is required (ordinals 1–999, up to 1000 pairs).
  • Optional explanation/NNN.txt (UTF-8, ≤1024 chars) adds an explanation for the test case of the same number; shown to contestants below the sample.
  • Every test case is imported as secret.
  • A non-empty author is preserved. If omitted, you are recorded as both owner and author.
  • A packaged image must pass the same upload rules as the manual upload (PNG, JPEG, or WEBP, max 2 MB).
  • Categories are linked only when they already exist (matched by name); unknown categories are dropped.
  • Web-only fields (color, language_limits) are accepted and ignored.
