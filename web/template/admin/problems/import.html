ZIP Format

Directory layout (exported by NOCA)

/
+-- problem.json              ← required
+-- statement.pdf or statement.md  ← one required
+-- in/
|   +-- 001.in
|   +-- 002.in
+-- out/
|   +-- 001.out  (or 001.sol)
|   +-- 002.out  (or 002.sol)
+-- explanation/             ← optional
    +-- 001.txt

Flat layout (alternative)

/
+-- problem.json
+-- statement.pdf or statement.md
+-- 001.in
+-- 001.out  (or 001.sol)
+-- 002.in
+-- 002.out  (or 002.sol)

problem.json schema

Field Type Required
title string required
time_limit_ms integer ≥ 1 required
memory_limit_kb integer ≥ 1 required
pids_limit integer ≥ 1 required
color hex string e.g. #ff0000 optional
author string optional
notes string optional
output_limit_in_bytes integer or null optional
categories array of strings optional
language_limits object optional

Validation rules

  • Either statement.pdf or statement.md is required — import fails without one
  • statement.md must not contain external links, images, or URLs
  • Per-language language_limits entries may include repetitions; fallback limits always use 1 repetition
  • Per-language limits for languages not allowed in this contest are skipped during import
  • Legacy top-level repetitions metadata is accepted and ignored during import
  • At least 1 test case pair is required
  • Test case ordinals: 1–3 digit integers (1–999, up to 1000 pairs)
  • Both input and output files must be present for each ordinal
  • Optional explanation/NNN.txt (UTF-8, ≤1024 chars) adds an explanation for the test case of the same number; shown to contestants below the sample
