Shared confirmation modal for removing a problem's custom validator, used by the Web and Arena problem-edit pages. Without its validator a problem's sample interactions have nothing to illustrate, so the admin must choose what happens to them: the two confirm buttons carry `keep_interactions=true|false`, the exact strings both Save routes accept -- a `bool` would let FastAPI coerce `1`, `on` and `yes` into a choice between hiding data and destroying it. The modal is its own form posting straight to the removal endpoint, like every other action on the judgment-data pages. It briefly submitted the editor's single Save instead (`form="edit-form"`), which is why the buttons must carry their own action now -- that form does not exist on these pages, so confirming did nothing at all. Context: validator_remove_url str where the confirmation posts interaction_count int non-hidden interactions the problem currently has #}
