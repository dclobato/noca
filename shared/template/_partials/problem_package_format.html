language_limits object




Keyed by language id; each value overrides the problem-level limits for that language.
All five keys are accepted, output_limit_in_bytes may be null.



"language_limits": {
  "python3": {
    "time_limit_ms": 3000,
    "memory_limit_kb": 262144,
    "pids_limit": 64,
    "output_limit_in_bytes": 1048576,
    "repetitions": 3
  }
}

{% endif %}

Interactive problems (custom validator)



A package may ship a custom interactive validator: put its UTF-8 source at
validator/source.txt and declare it in problem.json. The
language_id must be an active judge language.



"custom_validator": {
  "language_id": "cpp20",
  "source_file": "validator/source.txt"
}


    

  • 
An interactive package ships its test cases as in/NNN.in files
only: a case has no expected output, it holds the data that parametrizes the
validator for one round. Any out/NNN.out in the archive is ignored.

    • 

  • 
The imported validator is staged as a candidate and compiled asynchronously. The problem cannot
accept submissions until it compiles successfully.

    • 

  • Full exports of an interactive problem include the validator source; public exports never do.
    • 



Validation rules


    
{% if is_arena %}

  • 
statement.md is required and must not contain external links, images, or URLs.

    • 
{% else %}

  • 
Either statement.pdf or statement.md is required — import fails without one.

    • 

  • 
statement.md must not contain external links, images, or URLs.

    • 
{% endif %}

  • 
At least one input/output test-case pair is required (ordinals 1–999, up to 1000 pairs), and both
files must be present for each ordinal.

    • 

  • 
Optional explanation/NNN.txt (UTF-8) adds an explanation for the test case of the same
number; shown to contestants below the sample.

    • 

  • 
Test cases are imported as secret, unless the package declares a custom validator —
then they are all imported as public samples.

    • 

  • 
An optional illustration image is displayed below the statement. It must be a GIF, PNG, JPEG, or
WEBP of at most 2 MiB and 2048 × 2048 pixels — the same rules as the manual upload on
the problem form. When
problem.json names an image, that file must be present in the package;
otherwise a root-level image file is picked up automatically. image_caption is shown
below it.

    • 
{% if is_arena %}

  • Categories are linked only when they already exist (matched by name); unknown categories are dropped.
    • 

  • 
A non-empty author is preserved. If omitted, you are recorded as both owner and author.

    • 

  • 
Contest-only fields (color, language_limits) are accepted and ignored.

    • 
{% else %}

  • Categories are matched by name and created on the fly when they do not exist yet.
    • 

  • 
Per-language language_limits entries may include repetitions; fallback
limits always use 1 repetition.

    • 

  • Per-language limits for languages not allowed in this contest are skipped during import.
    • 

  • 
Legacy top-level repetitions metadata is accepted and ignored during import.

    • 
{% endif %}
