Sticky save bar and pane strip for the problem *definition* editor, shared by both modules. Every pane stays mounted and every control attaches to the detached `#edit-form` by `form="edit-form"`, so Bootstrap only toggles visibility -- switching panes cannot lose typed input. That is affordable here because these panes are a handful of fields belonging to one transaction; judgment data is neither, and lives on its own pages behind the "Judgment data" link. The strategy badge is deliberately read-only markup and never an input: a problem's strategy is immutable after creation, so the editor offers no way to change it. It also carries the "re-select these uploads" notice, because that is a property of the whole save rather than of any one pane, and the archive an author lost may belong to a tab they are not currently looking at.
