Markdown Syntax Examples

LaTeX

Use inline math with single $: 

$x^2 + y^2 = z^2$

Use double $$ for display math: 

$$x^2 + y^2 = z^2$$

Escape a literal dollar sign with \$: 

The price is \$10.

Common symbols:

\frac{a}{b} → fraction
x_2 → subscript
\neq, \le, \ge → ≠, ≤, ≥
\alpha, \beta, \Omega → Greek letters
\sum, \int → Σ, ∫
\sqrt{x} → square root

Mermaid

Use a fenced code block with mermaid: 

```mermaid
graph TD
    A[Start] --> B{Decision}
    B -->|Yes| C[End]
    B -->|No| D[Loop]
    D --> B
```

Keywords:

flowchart, sequenceDiagram, classDiagram
-->, ---, ==> → arrows
[], {}, () → shapes
|text| → labels

NOCA directives

Put each directive on its own line. Blank lines are optional; the renderer separates valid directives automatically. Each directive applies only to the next table or paragraph.

The editor toolbar inserts a starter table with table-border on and table-align left, and can apply paragraph alignment directives at the cursor.

Table borders

::: table-border off

| Name | Score |
| --- | ---: |
| Ada | 100 |

Use off for a borderless table or on to explicitly enable borders. Borders are on by default.

Table alignment

::: table-align center

| Name | Score |
| --- | ---: |
| Ada | 100 |

Flush the whole table left, center, or right.

Paragraph alignment

::: align center

This paragraph is centered.

Accepted alignment values are left, center, and right.
